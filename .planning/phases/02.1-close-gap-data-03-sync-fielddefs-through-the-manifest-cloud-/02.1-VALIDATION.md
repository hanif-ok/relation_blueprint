> Per-phase validation contract for feedback sampling during execution.

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Vitest 4.1.9 (unit; jsdom + fake-indexeddb). Playwright 1.61.1 exists but is not needed here. |

| **Full suite command** | `npm test` (`vitest run`) |
| **Estimated runtime** | ~68s full unit suite (small repo — run all) |

> **Known caveat (project memory):** under heavy machine load the Vitest fork pool false-fails
> with "Failed to start forks worker / Timeout". Re-run `npx vitest run --no-file-parallelism`
> to confirm it's environmental, not a code defect.

---

## Sampling Rate

- **After every task commit:** Run `npm test` (full unit suite, ~68s — small repo).
- **After every plan wave:** Run `npm test`. No new E2E needed — sync-internal fix, no UI surface.
- **Before `/gsd-verify-work`:** Full unit suite green (existing E2E unaffected). Re-run with `--no-file-parallelism` if a fork-timeout appears.
- **Max feedback latency:** ~70 seconds
