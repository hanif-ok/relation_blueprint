<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| node/edge labels → Cytoscape canvas text | User-authored entity names + relationship labels drawn on the graph |
| npm install (cytoscape, react-cytoscapejs) | New third-party code enters the build |
| relationship endpoints → graph edges | Links may reference deleted/endpoint-less entities |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering / Info-disclosure (XSS) | Graph node/edge labels | mitigate | Labels render as Cytoscape canvas text — never `dangerouslySetInnerHTML` / DOM injection |
| T-04-04 | Denial of Service (resource) | Node avatar object-URLs on element rebuild | mitigate | Resolve URLs in an effect keyed by photo hash; revoke on unmount / hash change (no leak) |
| T-04-10 | Denial of Service (crash) | Edge over an endpoint-less / deleted-endpoint link | mitigate | `toGraphElements` drops links missing fromId/toId; reactive rebuild removes edges to deleted nodes (no dangling edge) |
| T-04-SC | Tampering (supply chain) | `npm install cytoscape react-cytoscapejs` | mitigate | Both packages audited OK in RESEARCH § Package Legitimacy Audit (real source repos, high downloads, no postinstall); pinned versions; no `[ASSUMED]`/`[SUS]`/`[SLOP]` — no blocking-human checkpoint required |
</threat_model>
