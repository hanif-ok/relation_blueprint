<objective>
Make the relationship graph's nodes draggable (viewer-only) with durable, sticky positions and a Reset-layout escape hatch. Drag rearranges the layout only — it must never touch a repository row. Adding an entity no longer blows away the hand-arranged layout; only the newcomer is auto-placed. This is the POL-02 half of the graph work; it also introduces the `suspendSaveRef` save-guard that Plan 04's ego overlay depends on.

Purpose: deliver POL-02 (D-07/D-08/D-09) by extending GraphView's existing once-attach `registerCy` + position cache, preserving the viewer-only contract and the tap→ProfileSidebar bridge.
Output: grabbable nodes, dragfree persistence, place-newcomer-only partial cache, a Reset-layout button, and the updated e2e spec.
</objective>
