## Interface Context for Executors

Targets the Plan 02 `StorageProvider` interface (`ensureFolder/list/readFile/writeFile/overwriteFile/delete/stat`) and the `Manifest`/`ShardPointer` types. The commit sequence (RESEARCH ## Pattern 2) is the contract:
1. For each dirty shard: `writeFile` a NEW immutable file -> `newShardFileId`.
2. For each new media blob: `writeFile` `media/<hash>` (content-addressed = idempotent).
3. Build `manifest'` = clone with swapped shard pointers + `version++` + `updatedAt=now`.
4. COMMIT: copy current manifest to `backups/manifest-<prevVersion>.json` (rolling, keep last 5), THEN `overwriteFile` the canonical manifest with `manifest'` — this single write is the ONLY commit point.
5. On success: mark local records `dirty=false`. THEN GC orphaned old shard files.

Plan 06 (Drive adapter) and Plan 07 (export) consume `serializer` (entities<->shards) and `manifest` helpers.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local DB -> cloud commit | The commit sequence is the only place the durable copy is mutated; an interruption here is the primary data-loss risk |
| cloud manifest -> reconcile load | The manifest read on open is untrusted-at-rest and validated before use |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Denial of Service / data loss | Interrupted commit (crash/401/quota/network) | mitigate | Manifest-pointer swap: new immutable files first, single small-manifest commit, rolling backup, GC only after success — proven by `tests/sync/atomicity.test.ts` (STOR-05) |
| T-05-02 | Tampering | Corrupt/malicious manifest read on open | mitigate | `ManifestSchema.parse` validates; on parse failure fall back to the most recent `backups/manifest-*.json` (RESEARCH ## Security Domain V5) |
| T-05-03 | Tampering | Stale shard masquerading as current | mitigate | Per-shard `hash` + `updatedAt` in the manifest; reconcile trusts the manifest pointers, and content-addressed media cannot be silently swapped |
</threat_model>
