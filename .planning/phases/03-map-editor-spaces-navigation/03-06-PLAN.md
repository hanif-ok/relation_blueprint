<objective>
Deliver MAP-06 + the MAP-07 descend half as a vertical slice: a distinct portal-blue door-arch glyph (D-06), single-click-select / double-click-navigate interaction (D-07), inline create-or-pick of the target map on drop (D-08), and establishing the parent→child hierarchy so portals double as the "descend" navigation (D-10, complementing the breadcrumb "ascend" from 03-02). Output: `PortalGlyph`, `PortalTargetPicker`, portal repository helpers, MapView portal placement + navigation, and tests + E2E.
</objective>
