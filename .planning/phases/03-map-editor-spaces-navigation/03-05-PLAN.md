<objective>
Deliver MAP-03 as a vertical slice: a per-map logical layers panel (D-04) where the user creates/renames/reorders layers and toggles show/hide/lock, with both shapes AND markers assigned to layers, rendered into the SINGLE physical content layer in logical order (RESEARCH Pattern 3 — never one Konva Layer per user layer). Also ships the D-20 marker name-label show/hide toggle. After this plan a user can organize map content into layers and control visibility/locking — capability they did not have before.

Purpose: MAP-03 is the last drawing-organization requirement; it depends on shapes existing (03-03) and markers being selectable/transformable (03-04) so objects can be assigned and z-ordered. The logical-over-physical layer model is the load-bearing performance decision (RESEARCH Pattern 3 / Pitfall 2).
Output: `LayersPanel`, marker `layerId` support, MapView logical-layer rendering, a move-to-layer control in the style popover, and tests + E2E.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user layer name → layers panel / canvas | Untrusted text crosses into a rendered row (and any canvas count chip) |
| stored MapDoc.layers + object.layerId → render | Corrupt layer data (dangling layerId, cyclic order) crosses into the render-set computation |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Information Disclosure | Layer names rendered in the panel (DOM) | mitigate | Layer names render as React text children (not innerHTML); inline-rename input value is plain text |
| T-03-14 | Tampering | Dangling object.layerId (points to a deleted layer) | mitigate | Render resolves an unknown layerId to the default/first layer rather than dropping the object or crashing |
| T-03-15 | Tampering | MapDoc.layers from cloud/backup (malformed order, missing fields) | mitigate | LayerSchema validates on load (03-01, optional-with-default); the migration guarantees at least one default layer |
| T-03-SC | Tampering | npm installs | accept | No new package installed in this plan |
</threat_model>
