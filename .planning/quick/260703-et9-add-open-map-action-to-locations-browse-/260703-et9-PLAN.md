<objective>
Add an "Open map ↗" action that lets the user open a Location directly on the canvas from the Locations browse list (and from a Location's profile sidebar). A Location IS a map, so this is a DISTINCT action from the People-only "Show on map ↗" — it sets that map active and switches to the Map view, reusing the existing active-map plumbing.

Purpose: Today the ONLY route to a specific map is the in-canvas MapSwitcher dropdown. A Location row's "Show on map" button is disabled ("Locations aren't placed on a map.") and clicking a Location row only opens its profile — never `setActiveMapId`. This closes that gap.

Output: An enabled `browse-open-map` action on Location rows + a matching `profile-open-map` action in the map profile, both wired to a new `App.openMap(id)` handler, plus an e2e regression test.
</objective>
