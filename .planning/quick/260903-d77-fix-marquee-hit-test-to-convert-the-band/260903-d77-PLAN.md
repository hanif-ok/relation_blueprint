Fix the marquee hit-test coordinate-space defect: the rubber-band is captured in SCREEN pixels but
hit-tested against WORLD-space object boxes, so banding silently misses (or wrongly catches) objects
whenever the Stage has been panned or zoomed.

selected." The defect shipped in quick-260821-nac and survived quick-260902-nfs because every
marquee test asserts at the identity view. 260902-nfs made it VISIBLE (the selection is now acted
upon — delete / move / re-layer) rather than merely outlined.

Output: a pure exported `screenBoxToWorld` helper in `marquee.ts`, one call site in
`finishMarquee`, a corrected module header, a unit-test matrix over the conversion, and an e2e
regression pair that pans and zooms the Stage BEFORE banding.
</objective>
